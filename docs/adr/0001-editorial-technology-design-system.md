# 0001. สถาปัตยกรรม Editorial Technology บน PHP & Bootstrap 5

## สถานะ

ยอมรับแล้ว (Accepted)

## บริบท (Context)

เว็บไซต์สาขาวิชาเทคโนโลยีธุรกิจดิจิทัลต้องการสื่อสารภาพลักษณ์ "Human-designed Digital Technology" ให้ความรู้สึกร่วมสมัย มีความเป็นมนุษย์ และมีเอกลักษณ์ของงานออกแบบกราฟิกดีไซน์ที่เข้าใจเทคโนโลยี โดยหลีกเลี่ยงงานดีไซน์สำเร็จรูปของ SaaS, Cyberpunk, หรือ AI-generated aesthetic (เช่น Glassmorphism, 3D float, Neon)

ขณะเดียวกัน โจทย์ต้องการแนวทางแบบ **Mobile-First** (เน้นการใช้งานบนมือถือขนาด 390px เป็นหลัก ก่อนขยายสู่ Tablet และ Desktop) และเลือกใช้เทคโนโลยี **PHP + Bootstrap 5.3 + MySQL**

## การตัดสินใจ (Decision)

1. **การควบคุมการแสดงผล (CSS Architecture)**: ใช้ Bootstrap 5.3 เฉพาะโครงสร้างพื้นฐาน (Reboot, Flex, Grid) แต่ **Override CSS Variables (`--bs-*`) ทั้งหมด** ด้วย Design Tokens เฉพาะตัว โดยจัดแบ่งโครงสร้าง CSS แบบโมดูลาร์ (`tokens.css`, `base.css`, `components/*.css`, `pages/*.css`, `admin/*.css`) และเชื่อมโยงผ่าน `assets/css/site.css` และ `assets/css/admin.css`:
   - รัศมีขอบมน (Border Radius): 0–4px (ให้ความรู้สึกแม่นยำแบบสิ่งพิมพ์/งานเทคนิค แทนความโค้งมนแบบแอปทั่วไป)
   - เงา (Box Shadow): ไม่ใช้เงาฟุ้งแบบพลาสติก แยกมิติด้วยเส้นคั่น 1px (`#DCE6EC`) และสีพื้นสลับ (`#F4F8FA`)
   - สัดส่วนสี: พื้นหลังขาว/เทาอ่อน (`#FFFFFF`, `#F4F8FA`) ~65%, ฟ้าอ่อน (`#E6F1F5`, `#B9DCEB`) ~20%, กรมท่า Deep Navy (`#17324D`) ~10%, ส้มอบอุ่น Accent (`#E99A4A` / `#B5601F`) ~5%
   - ระบบฟอนต์: **Kanit** (Display & Headings), **Prompt / Anuphan** (เนื้อหาหลักภาษาไทยที่อ่านสบายตา) ร่วมกับ **IBM Plex Mono** (ตัวเลขทางเทคนิค, วันที่, รหัสวิชา, Label กำกับ Section)
2. **ระบบการนำทางบนมือถือ (Mobile Navigation)**: ใช้ **Bottom Navigation Bar 5 แท็บ** (สูง 64px) ที่เหมาะกับการใช้งานด้วยนิ้วโป้งมือเดียว และเปลี่ยนเป็น Top Navigation แนวนอนบนหน้าจอขนาดใหญ่
3. **การนำเสนอตารางเรียนบนมือถือ**: ใช้ **Day Selector (จ.–ศ.) + Vertical Timeline** เพื่อป้องกันปัญหาตารางเรียนกว้างล้นจอบนมือถือ 390px พร้อมตารางเต็ม 5 วันบนเดสก์ท็อปที่คงความคมชัดแบบ Refined Editorial Brutalism (ขอบ 1px คมชัด ปราศจากเงามัว)

## ผลลัพธ์และข้อดี (Consequences)

- ระบบโหลดเร็ว น้ำหนักเบา ไม่พึ่งพา Library ภายนอกที่ไม่จำเป็น
- หน้าตาเว็บไซต์มีความประณีตและมีเอกลักษณ์เฉพาะตัว ไม่ซ้ำกับเว็บสำเร็จรูปทั่วไป
- รันบนสภาพแวดล้อมมาตรฐาน (XAMPP / Laragon) ได้ทันทีโดยไม่ต้องผ่านกระบวนการ Build
- รักษาสมดุลระหว่างความสวยงามเชิงบรรณาธิการกับการใช้งานจริงบนอุปกรณ์พกพา
