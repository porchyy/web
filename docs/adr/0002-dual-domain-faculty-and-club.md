# 0002. การแบ่งสัดส่วนข้อมูลอาจารย์และชมรมวิชาชีพในหน้า 07

## สถานะ

ยอมรับแล้ว (Accepted)

## บริบท (Context)

ในโจทย์กำหนดหัวข้อที่ 7 ว่า "อาจารย์ในแผนก (หัวหน้าชมรม, สมาชิกคนอื่น ๆ)" แต่ในระบบจัดการหลังบ้าน (ข้อ 6) มีการแยกเมนูระหว่าง "จัดการรายชื่ออาจารย์ในแผนก" (`admin/teachers.php`) และ "จัดการสมาชิกชมรม" (`admin/club.php`) อย่างชัดเจน ซึ่งในโลกความเป็นจริง อาจารย์ประจำแผนกและนักเรียนคณะกรรมการชมรมมีบริบท หน้าที่ และข้อมูลที่ต่างกัน

## การตัดสินใจ (Decision)

1. รวมข้อมูลทั้งสองกลุ่มไว้ในหน้า `pages/teachers.php` ตามโครงสร้างที่โจทย์กำหนด (ไม่เพิ่มหน้าใหม่ในเส้นทางสาธารณะ)
2. แบ่งหน้า `pages/teachers.php` ออกเป็น 2 ส่วน (Sections) ทางสายตาอย่างชัดเจน:
   - **ส่วนที่ 1: คณาจารย์ในสาขาวิชา**: แสดงหัวหน้าแผนก (Featured Leadership Block) และอาจารย์ผู้สอนประจำสาขา (วุฒิการศึกษา, ความเชี่ยวชาญ, อีเมล)
   - **ส่วนที่ 2: ชมรมวิชาชีพเทคโนโลยีธุรกิจดิจิทัล**: แสดงหัวหน้าชมรม (ประธานชมรม) และคณะกรรมการ/สมาชิกชมรม (ระดับชั้น, หน้าที่รับผิดชอบ)
3. หากไม่มีรูปถ่าย ให้แสดงเป็น Monogram อักษรย่อสไตล์ Technical Monogram แทนไอคอนเงาคนสีเทาสำเร็จรูป
4. ในส่วนหลังบ้าน (`admin/teachers.php` และ `admin/club.php`) ใช้ระบบ Interactive Tree Slots พร้อมกลไก Position Swap (เมื่อลากการ์ดสมาชิกไปวางทับตำแหน่งหัวหน้า จะสลับตำแหน่งเป็นหัวหน้าคนใหม่ และปรับบทบาทหัวหน้าเดิมลงสู่รายชื่อสมาชิกโดยอัตโนมัติ พร้อมบันทึกลำดับใน MySQL ทันที)

## ผลลัพธ์และข้อดี (Consequences)

- รักษาโครงสร้าง 7 หน้าตามเงื่อนไขอย่างเคร่งครัดโดยไม่เพิ่มหน้าใหม่
- ผู้ใช้งานเข้าใจสถานะของบุคคลในภาพได้ทันที ไม่เกิดความสับสนระหว่างครูกับนักเรียน
- ผู้ดูแลระบบจัดการโครงสร้างองค์กรได้สะดวกและแม่นยำผ่านระบบลากวางสลับตำแหน่ง
